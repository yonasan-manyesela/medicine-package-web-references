Web Reference Annotation Guide

Purpose

Annotate whether the retrieved image (right) shows packaging of the same medicine as the query image (left).

Matching criteria

Compare the information visible on both packages:

  1. Brand name
  2. Active ingredient(s)
  3. Strength per unit (e.g., 500 mg per tablet or 125 mg per 5 mL)
  4. Dosage form (e.g., tablet, dispersible tablet, capsule, suspension)

How to decide

  • Same medicine: all four criteria match.
  • Different variant: the brand matches, but at least one of the other three criteria differs.
  • Different product: the brand names differ, or no medicine package is shown.
  • Cannot determine: no difference is identified, but the information needed to confirm a match is missing or unreadable.

Optional flags

M — Packaging difference

Select when the packages differ in pack size, unit count, printed age/weight instructions, language, country, logo, colour, or design.

Use only when the medicine matches or cannot be fully determined.

C — Part of a larger image

Select when the retrieved package appears as part of a collage, document, advertisement, or wider scene, rather than as the main subject of the image.

Do not select C simply because the package is held in a hand or shown alongside its own bottle or blister.

W — Watermark or overlay

Select when text or graphics have been added over the retrieved photograph, such as a stock-photo watermark, website logo, price, or banner.

Do not select W for text printed directly on the package.

Multiple flags may be selected when applicable.

Important

Use only the two displayed images. Do not use external searches or additional information.
